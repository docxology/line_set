## Shared transport requirements

Native owners retain schema/version, normalized inputs, effective policy,
native registry identity, evaluator revision, resolved date, typed intake
dispositions and verbatim outputs under the optional [profile](../evidence/README.md).
They implement their own exporters and replay; Line Set documents the convention.
Witness must keep envelope validity, native report correspondence, source
provenance and archival authentication separate, with exact subject binding.
Unavailable evidence is a replay prerequisite failure, never a false assertion.

Owner receipts must cover changed policy/context identity, changed input identity
with unchanged outcome, changed envelope identity, separate correspondence,
consistent rehash without authentication, protected references and unchanged
native results. The [case library](cases.json) supplies prompts, not receipts.
No work is marked verified from a source trace or another thread's existence.
