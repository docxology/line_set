# data

Claim ledgers for the line_set omnibus: `claim_ledger.yaml` (bibliography/claim
declarations) and `formalism_claim_ledger.json` (formalism cross-references
the render engine's evidence registry must resolve). `formalism_claim_ledger.json`
is GENERATED by `scripts/gen_formalism_ledger.py`; never hand-edit.
Its numeric rows cover scalar census fields, per-line counts and derived repeat
totals from the reading record. Regenerate it whenever that record changes.
See [AGENTS.md](AGENTS.md).
